# 学习小园地（小学三年级）

> 入口：「我的」→ 学习小园地；游戏大厅 → 学习小园地。受管理员权限控制（key: `study`）。

## 一、模块

| 模块 | 形式 | 题量 | 说明 |
|---|---|---|---|
| 语文·阅读理解 | 短文 + 四选一 | 8 篇 | 考查季节/比喻/道理等，答后显示解析 |
| 语文·生字学习 | 组词判断对错 | 21 题 | 易混字（瓣/辫、艳/豌豆等） |
| 英语·单词学习 | 中文 → 四选一英文 | 25 题 | 三年级词汇 |
| 数学·口算 | 四选一 | 10 题 | 三年级乘除/加减 |

## 二、玩法机制

- 每轮从所选模块随机抽 **5 题**，答对 +10 分，即时绿色/红色反馈 + 解析（错题也显示正确答案）
- 结算按正确率评星；累计积分存本机 `wx.setStorageSync('study_score')`（刻意不上传云端，避免集合污染，换设备不保留）
- 选项点击带震动反馈

## 三、加题指南（重点）

题库全部在 [pages/study/data.js](../miniprogram/pages/study/data.js)，四个数组按模块导出：

```js
// 阅读理解：{ text: 短文, q: 问题, opts: [4个选项], a: 正确下标0-3, why: 解析 }
const READ = [{ text: '…', q: '…', opts: ['…','…','…','…'], a: 1, why: '…' }];

// 生字判断：{ z: 生字, c: 组词, ok: 组词是否正确, why: 解析 }
const WORD = [{ z: '瓣', c: '花瓣', ok: true, why: '…' }];

// 英语：{ cn: 中文, opts: [4个英文], a: 正确下标, why: 解析 }
const ENG = [{ cn: '苹果', opts: ['apple','pear','peach','plum'], a: 0, why: '…' }];

// 口算：{ q: 算式, opts: [4个答案], a: 正确下标 }
const MATH = [{ q: '24 ÷ 6', opts: ['3','4','6','8'], a: 0 }];
```

往对应数组追加对象即可，**纯前端改动**，重新编译生效，无需部署云函数。
注意：`a` 是下标（从 0 起）；`opts` 必须恰好 4 项（WORD 为判断题除外）。

## 四、扩展方向（可选）

- 语文：古诗背诵（上下句配对）、看图写话评分
- 英语：听音选词（WebAudio 合成不现实，需录音素材放云存储）
- 增加"错题本"：把答错的题记入本机 storage 重练
- 若要多设备同步积分：新增 `study_scores` 集合 + 云函数 action（参考 game.js 写法），改 `study.js` 的读写点
