# 家庭小游戏与权限管理

> 入口：「我的」→ 家庭小游戏，或 tab 直达游戏大厅（pages/games/games）。
> 大厅 6 个项目：五子棋(gomoku)、俄罗斯方块(tetris)、飞机大战(plane)、蹦蹦大陆(benben)、炸弹小子(bomber)、打牌记分(score)。
> 学习小园地(study)已从游戏大厅移除，入口保留在「我的」页（docs/study.md）。

## 一、权限管理（管理员授权）

- **数据**：`members.game_perms = { gomoku, tetris, plane, benben, score, study }`，缺省视为开放
- **云函数**：`game.getPerms`（成员查自己；管理员附带全员列表）、`game.setPerm`（仅 admin）
- **管理页**：游戏大厅底部「游戏权限管理」（仅管理员可见）→ 成员 × 项目开关，即时保存并清前端缓存
- **前端守卫**：每个游戏/学习页 `onLoad` 调 [utils/perms.js](../miniprogram/utils/perms.js) 的 `check(key)`，被禁项目在大厅显示红色「已禁用」、点击提示联系管理员，直接跳转也会被拦（云函数二次把关）

## 二、五子棋（双人 / 人机 / 联机）

- 本地棋盘：Canvas 2d 手绘 15×15；联机进入对局时才创建 canvas，初始化完成后才绘制（时序坑已修：`resetBoard` 不得重置 `pad/cell` 几何参数）
- 人机：简单 AI（防守+进攻评分）
- **联机同步**（房间存 `gomoku_rooms`，4 位房码）：
  1. 数据库 `watch` 监听房间文档 → 变更时本地 `normalizeDoc` 规范化直接渲染（零额外往返）
  2. watch 无权限静默失效时 → **1 秒轮询** `gomoku.get` 兜底
  3. 自己落子：**本地乐观渲染**立即出子出声，`gomoku.move` 成功后直接应用返回的最新快照（云函数已内联快照，省一次 get）；失败回滚为服务端状态
  4. 身份判定：本地记录 `_isHost`（create/join 时确定，重赛换色不变），`applyRoom` 收到快照时校准
- 音效：WebAudio 合成——落子（黑低白脆）、胜负旋律、五声音阶背景音乐循环；顶部 🔊/🔇 开关（存 `gomoku_muted`）
- 流程：建房 → 对方凭码加入 → 双方准备 → 开始；认输/再来一局（换先手）/离开

## 三、打牌记分（score）

- 4 位房码建房/加入，转账式记分「我给对方 +N、自己 −N」，云端 `score.adjust` 记账
- 快捷分值 **1/2/4/8/16/32** + 自定义弹窗（1–9999 手工录入）
- **下拉刷新**：重拉房间快照，同步每人分数与记分日志
- 房间失效自动退回大厅；日志面板可查每笔给分

## 四、俄罗斯方块（tetris）

单机，Canvas 渲染，标准七种方块 + 消行计分 + 逐级加速（8 行/级，起始 820ms/格，最快 260ms/格）：

- **棋盘**：10×18 格，画布 860rpx 高撑满屏宽（unit 取宽/高较小值），右侧预留 76px 预览列，游戏区带白色外框
- **下一个预览**：画布右上角「下一个」面板实时绘制迷你方块（颜色同棋盘）
- **消行闪光**：满行先白色脉冲闪烁 3 次（320ms）再结算消行，动画期间暂停重力与操作，暂停时立即结算避免状态不一致；消行音按行数升调琶音
- **音效/BGM**：WebAudio 合成——旋转/移动/锁定/直落/消行/游戏结束；原创循环 BGM《货郎》(Korobeiniki，公有领域) 32 步方波旋律 + 三角波低音；🔊/🔇 存 `tetris_muted`
- 切后台自动暂停（闪光中途切后台会立即结算消行）

## 五、飞机大战（plane）

单机闯关，Canvas 2d + requestAnimationFrame：

- **关卡**（10 关，每关波次编队 + 关底 BOSS，每关约 40~90 秒）：
  - 波次数 4→9、敌机速度 ×1→×1.45、大机血量 5→8、BOSS 血量 78→330 逐级递增
  - 编队类型：小机 V 字/横排、大机 solo + 护航小机
- **BOSS**：每关登场前播「⚠️ BOSS 来袭」警告；弹幕按关卡分四档（三向散射 → 5 连扇形 → 扇形+螺旋 → 扇形+螺旋+双瞄准弹）；跌破半血**狂暴**（红光脉动、巡航提速、节奏加快）；配色随关卡轮换色相
- **生命/大招**：5 条命；大招=**垂直激光束**（900ms 扫屏：清光束内弹幕、持续灼伤敌机，对 BOSS 约 72 血/次），**起始 1 个、上限 3**；**充能制（非道具）**：每积满 800 分 +1、每击落 40 架 +1，满仓时欠账保留、用完立即回补，换命保底 1 次
- **道具**：⚡火力+1（5 级）、🛡护盾 5 秒、❤生命+1、👶**宝宝**（最多 5 个，环绕跟随，齐射**跟踪导弹**：优先锁 BOSS>大机>小机，转向追踪 + 尾焰拖迹，命中 2 伤）
- **战机外观进化**：火力 1-5 级对应 蓝隼→青锋→银翼(侧挂舱)→紫电(前掠翼)→金耀(光环+双尾焰)，翼展/座舱/航行灯/尾焰逐级华丽
- **音效**：WebAudio 合成——分类型爆炸（白噪声+低通滤波）、激光嗡鸣、宝宝获得音、道具音、BOSS 警报/狂暴低吼、过关/胜负旋律、背景音乐行进循环；HUD 🔊/🔇 开关（存 `plane_muted`）
- 操控：手指拖动战机自动开火；受击 2 秒无敌闪烁、火力降 1 级；切后台自动暂停

## 六、蹦蹦大陆（benben）

横版平台跳跃（MVP 1-1 绿草原），**横屏**（页面 json `pageOrientation: landscape`）+ 王者荣耀式**动态镂空按键**，Canvas 2d + 固定步长 60fps 逻辑循环，原创像素绘制、无外部资源：

- **按键**：画面只占上部 70%（世界 240px 映射），底部 30% 为沙色按键带；左侧 46% 屏幕为**动态摇杆区**——手指按在区域任意位置摇杆即从触点出现（王者荣耀式），摇帽跟随手指（限幅 44px、死区 8px），横向偏移量为模拟量：轻推慢走、推满快跑，反向拨杆快速刹车转向；未按时左下角显示虚线提示环；右下 A=跳（长按跳更高）、B=跑；按下缩放高亮（hover-class）
- **手感四要素**：土狼时间 6 帧 / 输入缓冲 8 帧 / 可变跳跃（按住每帧 -0.4 最多 12 帧）/ 松开快坠 ×1.5；重力 0.8、最大落速 12、走 3.2 / 跑 4.6、起跳 -11
- **关卡**：240×15 网格（16px tile），实心地面/砖块/？箱/单向平台/传送管/终点台阶；？箱 x=26、22 出变大果，其余出星币；大蹦蹦可碎砖 +50
- **敌人**：滚菇（踩扁 +100）、龟兵（踩缩壳→踢壳滑行，撞敌连杀 100/200/400/800 翻倍）；离屏休眠省性能
- **角色**：小/大两态；大受伤变小+2 秒无敌闪烁，小受伤死亡；3 条命，掉坑/超时死亡；碰胜利旗结算（高度分 + 剩余时间×10）
- **渲染**：天空渐变 + 三层视差（山/云 0.2、灌木 0.5），相机只向右推进（马里奥式），世界 240px 映射画布上部 70%
- **音效**：WebAudio 合成——跳/落地/踩/顶砖/碎砖/吃币/变大上行琶音/缩小下行琶音/死亡/踢壳/胜利旗旋律；原创 8-bit BGM（16 拍五声旋律 + 低音行进 + hi-hat 循环）；🔊/🔇 存 `benben_muted`，最高分存 `benben_best`
- **特效**：吃变大果金色光环脉动 + 星尘粒子爆发 + 震动反馈；碎砖飞溅、踩怪尘雾、缩小红雾、滑壳速度线；角色/怪物全矢量重绘（蹦蹦红帽圆徽+腮红+眨眼+跑步摆腿，滚菇斑纹怒目，龟兵六格龟壳）
- 切后台自动暂停；HUD：分数/星币/生命/时间/最高分 + 静音/暂停/退出

## 七、炸弹小子（bomber）

竖屏炸弹人式闯关（移植自 炸弹小子.html），Canvas 2d + 固定步长 60fps，原创矢量绘制 + WebAudio 合成音效，无外部资源：

- **关卡**：6 关选关（15×13 → 19×17 网格、砖密度 0.42→0.52、敌人 3→8 只、敌速 ×0.7→×1.2），外墙 + 偶数格不可破墙 + 随机橙砖；出生点（左上/右上）保护清空
- **操控**：左下固定摇杆（128px 底座 + 54px 摇帽，限幅 44px、死区 8px，模拟量输出 0.5-1.0 倍速）移动，速度平滑加减速、双轴斜行与贴墙滑行、主方向渐进吸附通道中心线；右下 💣 按钮放弹（炸弹放下后固定不动）
- **爆炸**：十字火焰（range 1-6）；砖被炸碎 28% 掉道具；火焰触及其他炸弹**链式引爆**（timer 压至 0.15s）；放弹后压住炸弹可直接走开，完全离开该格后炸弹恢复阻挡
- **道具**：💣炸弹+1、🔥范围+1、👟速度+0.4、❤️生命+1（上限 5），+50/+100 分
- **敌人**：史莱姆(紫)/幽灵(青)随机游走、猎手(红)3% 概率转向追玩家；炸死 +200，35% 掉道具；碰玩家扣血（2 秒无敌闪烁）
- **通关结算**：全灭怪物后右上出生区开启金色 🚪 出口，走进出口才过关；星级按用时+剩余生命评定（1-3⭐）；时间奖励 max(0, 3000-秒×20) + 生命×100；解锁进度存 `bomber_unlocked`/`bomber_progress`（本地存档）
- **音效**：放弹/爆炸(白噪声轰鸣)/道具/受伤/击杀/胜负旋律 + E 小调 16 拍 8-bit BGM；🔊/🔇 存 `bomber_muted`
- HUD：❤️生命/💣炸弹/🔥范围/⭐得分/🗺️关卡 + 静音/暂停/退出；切后台自动暂停；loop 带帧异常保护（连续 20 帧异常自动暂停）

## 八、新增一个可授权项目的步骤

1. `cloudfunctions/closetApi/actions/game.js` 的 `GAME_KEYS` 加 key
2. 游戏页 `onLoad` 调 `check('key')` 守卫
3. 大厅 `pages/games/games` 加入口与禁用标签
4. 重新部署云函数
