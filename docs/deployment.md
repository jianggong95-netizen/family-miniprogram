# 部署指南（微信云开发）

> 取代 v1 的飞牛OS/Docker 部署方式。云开发版无服务器，全部在微信开发者工具内完成。

## 一、前置条件

| 项 | 说明 |
|---|---|
| 微信开发者工具 | 稳定版即可，需登录开发者微信号 |
| 小程序 AppID | 个人主体即可（微信公众平台注册），填入 `project.config.json` |
| 云开发环境 | 开发者工具 →「云开发」→ 开通，记下**环境 ID** |

## 二、首次部署步骤

1. **配置环境 ID**：把环境 ID 填入 [miniprogram/utils/config.js](../miniprogram/utils/config.js) 的 `CLOUD_ENV_ID`（换环境只需改这一处）。

2. **上传部署云函数**：开发者工具文件树中右键 `miniprogram/cloudfunctions/closetApi` → **上传并部署：云端安装依赖**。

3. **初始化数据库集合**：云开发控制台 → 云函数 → `closetApi` → 云端测试，传入：

   ```json
   { "action": "system.init" }
   ```

   该接口幂等，自动创建 8 个集合（families/members/clothes/clothing_images/stock_records/dicts/gomoku_rooms/score_rooms），已存在的跳过。
   > ⚠️ 不执行这一步，首次绑定会报 `collection not exists: members`。

4. **创建家庭（管理员）**：编译运行小程序 → 进入绑定页 → 「创建家庭」→ 当前微信即成为管理员。其他家人凭 4 位邀请码在绑定页加入。

5. **发布**：
   - 体验：工具栏「上传」→ 小程序后台把成员加为**体验成员** → 扫码体验版
   - 正式：云开发版**可以提交审核发布**（HTTPS/备案域名的老约束不存在了），审核通过后家人直接搜索使用

## 三、日常更新

| 改动 | 操作 |
|---|---|
| 只改前端（pages/utils/components） | 重新编译/上传体验版即可，**无需动云函数** |
| 改了 `cloudfunctions/closetApi/**` | 必须重新「上传并部署：云端安装依赖」，前端改动 + 云端改动要同步生效 |
| 新增 action | 在 `closetApi/index.js` 的 ROUTES 注册 + 对应 `actions/*.js` 实现，然后重新部署 |

## 四、权限配置（易错点）

- **云存储**：建议「所有用户可读，仅管理员可写」；即便保持默认「仅创建者可读写」，图片展示也不受影响——因为换临时链接走的是云函数 `system.tempUrls`（管理端权限）。**不要**改成前端 `getTempFileURL` 直连换链，否则家人互相看不到彼此上传的图片。
- **云数据库**：集合权限设为「仅管理端可读写」即可——所有读写都经云函数完成，前端不直连数据库（联机五子棋的 watch 监听除外，它需要 `gomoku_rooms` 对登录用户可读；若不开读权限，watch 会静默失效，前端已内置 1 秒轮询兜底，功能不受影响只是延迟略高）。

## 五、费用与额度

- 云开发免费额度（1 环境）：读 5 万次/天、写 3 万次/天、存储 5GB、CDN 5GB/月 —— 家庭场景（≤7 人）远够用
- 超量可在控制台按量付费，无需改代码

## 六、故障排查

| 现象 | 原因与处理 |
|---|---|
| `collection not exists: xxx` | 未执行 `system.init`，见步骤 3 |
| 所有请求 toast「网络异常」 | `CLOUD_ENV_ID` 填错，或云函数未部署 |
| 一直跳绑定页 | 该微信 openid 不在 members 中：管理员在「成员管理」添加后，家人重新进入选择自己 |
| 看不到家人上传的图片 | 换链被改成了前端直连；恢复走 `system.tempUrls` |
| 五子棋联机棋盘空白 | 前端 canvas 初始化时序问题（已修），确认重新编译；若仍异常看控制台报错 |
| 云函数超时/内存告警 | 控制台查看 `closetApi` 日志，单函数默认 3s/256MB，可在配置里调 |
